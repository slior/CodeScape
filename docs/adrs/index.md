# Architecture decision records

These records are numbered in dependency order. A record comes after the records it depends on. Every record is accepted.

| Record | Accepted | Decision | Depends on |
| --- | --- | --- | --- |
| [001 - Split the pipeline into six packages](001-six-package-pipeline.md) | 2026-10-09 | The pipeline is six packages, and only analyze reads or writes the filesystem. | none |
| [002 - Build the repo as an npm and Nx TypeScript workspace](002-npm-nx-typescript-workspace.md) | 2026-10-09 | The repo is an npm workspace of `packages/*`, built with Nx and TypeScript. Node is 18 or newer. | [001](001-six-package-pipeline.md) |
| [003 - Test the Node packages with Jest](003-jest-for-node-packages.md) | 2026-10-09 | The five Node packages test with Jest. Specs are `*.spec.ts` beside the source. | [001](001-six-package-pipeline.md), [002](002-npm-nx-typescript-workspace.md) |
| [004 - Keep the shared contract in @sw3d/model](004-model-contract.md) | 2026-10-10 | `@sw3d/model` holds the shared types, ids, and serializer, and it does no I/O. | [001](001-six-package-pipeline.md) |
| [005 - Use a language-neutral code graph and parser plugins](005-language-neutral-code-graph.md) | 2026-10-10 | The code graph is language-neutral. A language is a `SourceParser` plugin, and TypeScript is the only one. | [001](001-six-package-pipeline.md), [004](004-model-contract.md) |
| [006 - Separate the unplaced city from the placed world](006-city-structure-and-world.md) | 2026-10-10 | compose returns a `CityStructure` with no poses. layout returns a `World` with poses and polylines. | [001](001-six-package-pipeline.md), [004](004-model-contract.md) |
| [007 - Identify nodes and edges with length-prefixed ids](007-length-prefixed-ids.md) | 2026-10-10 | Node and edge ids are length-prefixed, so a colon or hash in a path cannot collide. | [004](004-model-contract.md), [006](006-city-structure-and-world.md) |
| [008 - Take districts from npm workspaces](008-workspace-districts.md) | 2026-10-10 | Districts come from npm workspaces. A folder with no workspaces field is one district. | [001](001-six-package-pipeline.md), [004](004-model-contract.md) |
| [009 - Ignore files with gitignore rules](009-gitignore-discovery.md) | 2026-10-10 | Files are ignored with gitignore rules. The last matching pattern wins. | [001](001-six-package-pipeline.md), [005](005-language-neutral-code-graph.md), [008](008-workspace-districts.md) |
| [010 - Parse TypeScript with the compiler API](010-typescript-compiler-parser.md) | 2026-10-10 | The TypeScript parser uses the compiler API on the text it is given. It does not read the disk or the project's tsconfig. | [002](002-npm-nx-typescript-workspace.md), [005](005-language-neutral-code-graph.md) |
| [011 - Classify imports without a filesystem resolver](011-specifier-classification.md) | 2026-10-10 | An import specifier is classified by text rules. No filesystem resolver runs. A bare specifier is an external package. | [005](005-language-neutral-code-graph.md), [008](008-workspace-districts.md), [009](009-gitignore-discovery.md) |
| [012 - Build the containment tree from files and symbols](012-containment-tree.md) | 2026-10-12 | The city is a tree of one city, districts, buildings, and boxes, built from files and symbols. | [005](005-language-neutral-code-graph.md), [006](006-city-structure-and-world.md), [007](007-length-prefixed-ids.md), [008](008-workspace-districts.md) |
| [013 - Count mass as descendant boxes](013-box-mass.md) | 2026-10-12 | A box has mass 1, a portal has mass 0, and every other node sums its non-portal children. | [012](012-containment-tree.md) |
| [014 - Share one ground coordinate frame](014-ground-coordinate-frame.md) | 2026-10-14 | Y is up, +x is east, and +z is north. Pose x and z are the footprint's minimum corner. | [006](006-city-structure-and-world.md) |
| [015 - Write world.json with one canonical serializer](015-canonical-world-json.md) | 2026-10-10 | `serializeWorld` is the only writer of `world.json`. Key order, sort, and line endings are fixed. | [002](002-npm-nx-typescript-workspace.md), [006](006-city-structure-and-world.md), [007](007-length-prefixed-ids.md), [014](014-ground-coordinate-frame.md) |
| [016 - Lay the city out from the leaves upward](016-bottom-up-layout.md) | 2026-10-14 | Layout walks from the leaves upward. Stored poses are in world space. | [006](006-city-structure-and-world.md), [012](012-containment-tree.md), [013](013-box-mass.md), [014](014-ground-coordinate-frame.md) |
| [017 - Pack courtyard children by road weight](017-road-affinity-packing.md) | 2026-10-14 | Courtyard children are ordered by undirected road weight and packed into rows. | [014](014-ground-coordinate-frame.md), [016](016-bottom-up-layout.md) |
| [018 - Route streets with a deterministic search](018-deterministic-street-routing.md) | 2026-10-14 | Streets are a deterministic search on the 2-unit grid. Portal markers sit on the courtyard rim. | [014](014-ground-coordinate-frame.md), [015](015-canonical-world-json.md), [016](016-bottom-up-layout.md), [017](017-road-affinity-packing.md) |
| [019 - Keep warnings on the document and stop before a fatal error](019-warnings-and-fatal-errors.md) | 2026-10-14 | Warnings stay on the document and the command exits 0. A fatal error exits 1 and does not change `--out`. | [001](001-six-package-pipeline.md), [004](004-model-contract.md), [006](006-city-structure-and-world.md) |
| [020 - Draw one courtyard at a time](020-one-courtyard-viewer.md) | 2026-10-14 | The viewer draws one courtyard: the current parent's children, its edges, and its portals. | [001](001-six-package-pipeline.md), [006](006-city-structure-and-world.md), [012](012-containment-tree.md), [014](014-ground-coordinate-frame.md) |
| [021 - Build the viewer with Vite and Three.js](021-vite-and-three.md) | 2026-10-14 | The viewer is a Vite app drawn with Three.js. Only `main.ts` imports Three or touches the DOM. | [002](002-npm-nx-typescript-workspace.md), [020](020-one-courtyard-viewer.md) |
| [022 - Test the viewer with Vitest](022-vitest-for-the-viewer.md) | 2026-10-14 | Viewer tests run on Vitest. The Node packages stay on Jest. | [003](003-jest-for-node-packages.md), [021](021-vite-and-three.md) |
| [023 - Publish a snapshot by staging and rollback](023-snapshot-publish.md) | 2026-10-14 | A snapshot is published from a staging directory, with rollback if a later step fails. | [001](001-six-package-pipeline.md), [015](015-canonical-world-json.md), [019](019-warnings-and-fatal-errors.md), [021](021-vite-and-three.md) |
| [024 - Expose snapshot and view as the sw3d commands](024-snapshot-and-view-commands.md) | 2026-10-14 | The commands are `sw3d snapshot` and `sw3d view`. `view` serves the snapshot on localhost. | [009](009-gitignore-discovery.md), [019](019-warnings-and-fatal-errors.md), [023](023-snapshot-publish.md) |
| [025 - Split each package into modules by pipeline step](025-package-module-boundaries.md) | 2026-10-14 | Each package is split into modules by pipeline step. The public entry re-exports that step and defines nothing. | [001](001-six-package-pipeline.md), [004](004-model-contract.md), [008](008-workspace-districts.md), [009](009-gitignore-discovery.md), [010](010-typescript-compiler-parser.md), [011](011-specifier-classification.md), [012](012-containment-tree.md), [016](016-bottom-up-layout.md), [017](017-road-affinity-packing.md), [018](018-deterministic-street-routing.md), [019](019-warnings-and-fatal-errors.md), [020](020-one-courtyard-viewer.md), [021](021-vite-and-three.md), [023](023-snapshot-publish.md), [024](024-snapshot-and-view-commands.md) |
